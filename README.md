# へぇ〜！雑学クイズ

雑学・都道府県・世界の首都・元素記号・難読漢字・四字熟語・ことわざなど、11ジャンル・1000問以上の4択クイズです。1回10問、1問10点の100点満点。

遊ぶ: https://onasu-susu.github.io/quiz/

- `index.html` … 画面
- `style.css` … 見た目（色は先頭の `:root` で変えられます）
- `game.js` … ゲームの進み方・点数・結果
- `questions.js` … 手書きの「へぇ〜雑学」の問題
- `data.js` … ジャンルの一覧と、都道府県・首都・元素・漢字・四字熟語・ことわざ・暦・偉人の一覧（ここから問題を自動で作ります）
